# IT-КУРСЫ — статический сайт (без PHP и MySQL)

Обычные файлы HTML, CSS и JS. Сайт открывается двойным кликом по `index.html` и публикуется на GitHub Pages.

| Файл | Что в нём |
|---|---|
| `data.js` | **Все данные:** цены, направления, расписание, FAQ, контакты, готовые тексты, ссылка для заявок |
| `index.html` | Структура страницы |
| `assets/css/style.css` | Стили. Цвета логотипа заданы в `:root` в начале файла |
| `assets/js/main.js` | Вывод данных, форма заявки, кнопки «Копировать» |
| `google-apps-script.js` | Код для Google Таблицы (на сайте не используется, вставляется в Apps Script) |

## Как менять цены, расписание и контакты

Откройте `data.js` в любом редакторе, поменяйте значения, сохраните и обновите страницу.
Если сайт уже на GitHub, загрузите изменённый `data.js` в репозиторий (см. ниже).

## Заявки → Google Таблица

Пока `googleScriptUrl` в `data.js` пустой, форма открывает WhatsApp с готовым текстом заявки на номер из `settings.whatsapp`.

Подключение таблицы (5 минут, один раз):

1. Создайте новую таблицу на https://sheets.google.com, например «Заявки IT-КУРСЫ».
2. В меню **Расширения → Apps Script**.
3. Удалите всё в `Code.gs`, вставьте содержимое файла `google-apps-script.js` и нажмите 💾.
4. Вверху выберите функцию **setup** и нажмите **Выполнить**. Google попросит разрешение:
   **Проверить разрешения → ваш аккаунт → Дополнительно → Перейти к проекту → Разрешить**.
   В таблице появится лист «Заявки» с заголовками и списком статусов.
5. **Начать развёртывание → Новое развёртывание** → шестерёнка → **Веб-приложение**:
   - Запуск от имени: **Я**
   - У кого есть доступ: **Все**
   - нажмите **Развернуть** и скопируйте **URL веб-приложения** (заканчивается на `/exec`).
6. Вставьте ссылку в `data.js`:
   ```js
   googleScriptUrl: 'https://script.google.com/macros/s/XXXX/exec',
   ```
7. Проверка: откройте ссылку `/exec` в браузере. Должно показаться `{"ok":true,"message":"Приём заявок работает"}`.
   Затем отправьте тестовую заявку с сайта, она появится в таблице.

Статус заявки («Новая / В работе / Записан / Отказ») выбирается в таблице из списка, строка окрашивается по статусу.

> Если поменяли код в Apps Script: **Начать развёртывание → Управление развёртываниями → ✏️ → Версия: новая → Развернуть**. Ссылка останется прежней.

## Публикация на GitHub Pages

1. Зарегистрируйтесь на https://github.com и нажмите **New repository**: имя, например, `it-kursy`, тип **Public**, создать.
2. На странице репозитория: **uploading an existing file**. Перетащите **содержимое** папки `site`: `index.html`, `data.js`, папку `assets` и остальные файлы. Нажмите **Commit changes**.
3. **Settings → Pages**. В Source выберите **Deploy from a branch**, Branch: **main**, папка **/ (root)**, затем **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/it-kursy/`.

Чтобы обновить сайт, загрузите изменённый файл так же (**Add file → Upload files**) с той же папкой и тем же именем.

Свой домен: **Settings → Pages → Custom domain**, затем у регистратора домена добавьте записи по инструкции GitHub.
